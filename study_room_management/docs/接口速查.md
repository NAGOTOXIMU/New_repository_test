# 接口速查表

> 记不住函数名的时候翻这里。所有函数都在 `db/`、`repository/`、`services/` 下。
> 表里 `→` 后面是**返回值**。
>
> ⚠️ 本文件已按《数据库规范》口径全面更新：库名 `study_room_management`、用户用 `phone` 登录、
> 状态一律 TINYINT 数字、时间列 `create_time` / `update_time`、表名 `reservation_order` / `recharge_order`。

## 一、db/ —— 连接与事务

### `db/connection.py`

| 用法 | 说明 |
|---|---|
| `from db.connection import read_cursor, write_cursor` | 平时只用这两个 |
| `with read_cursor() as cur:` | 只读查询，自动开关连接，结果返回 dict |
| `with write_cursor() as cur:` | 写入，自动开关连接 + 提交/回滚 |
| `check_connection()` → `(bool, 说明)` | 连通性自检（排查问题用） |

### `db/uow.py` —— 事务（多步同成同败）

```python
from db.uow import uow

with uow() as cur:
    ...多条写操作，比如"扣钱 + 写预约"...
# 正常走完自动 COMMIT；中间抛异常自动 ROLLBACK
```

### `db/init_db.py` / `db/seed.py` —— 命令行工具

```bash
python -m db.init_db --with-seed --yes   # 建库建表 + 建索引 + 灌主数据
python -m db.seed --with-orders          # 再补历史订单，供数据看板演示
```

> ⚠️ `db/init_db.py` 用 **PyMySQL** 执行 SQL 脚本，**不认 `DELIMITER` / `SOURCE`**
> 这类 mysql 客户端命令。所有索引已直接写在 `01_schema.sql` 的 `CREATE TABLE` 里。

## 四、常用写法（照抄就行）

### 1. 查一条数据

```python
from repository import user_repo

user = user_repo.get_by_phone("13800000001")
if user is None:
    st.warning("没有这个用户")
else:
    st.write(user["nickname"])
```

### 2. 查一列数据画表格

```python
from repository import store_repo

stores = store_repo.list_all()
st.dataframe(stores, width="stretch", hide_index=True)
```

### 3. 写入（自动提交）

```python
from repository import store_repo
new_id = store_repo.create("新门店", "某地址")
st.success(f"新建成功，id = {new_id}")
```

### 4. 分页列表（服务端分页）

```python
from services import order_service

page = st.number_input("页码", min_value=1, value=1, step=1)
rows, total = order_service.list_my_orders(user_id, page=page, page_size=20)
st.dataframe(rows, width="stretch", hide_index=True)
st.caption(f"共 {total} 条，第 {page} 页")
```

### 5. 业务操作要接住 BizError

```python
from services import order_service
from services.exceptions import BizError

if st.button("确认预约"):
    try:
        # duration 单位是【分钟】，不是小时
        result = order_service.reserve(uid, seat_id, date, "10:00:00", 120, card_id)
        st.success(f"预约成功，扣费 {result['amount']} 元")
        st.rerun()
    except BizError as e:
        st.error(str(e))          # 余额不足、时段被抢…都在这
```

### 6. 表单里保存用户输入

```python
with st.form("f"):
    name = st.text_input("门店名")
    addr = st.text_input("地址")
    ok = st.form_submit_button("保存", width="stretch")

if ok:
    from services import store_service
    from services.exceptions import BizError
    try:
        store_service.create_store(name, addr)
        st.success("已保存")
        st.rerun()
    except BizError as e:
        st.error(str(e))
```

### 7. 登录态

```python
user = st.session_state["user"]       # 登录后一定有；app.py 已经拦过
uid  = user["user_id"]
role = user["role"]                   # "user" 或 "admin"

```

```python

if int(order["order_status"]) == ORDER_PENDING:
    ...
```

## 五、几个容易忘的点

| 事 | 怎么做 |
|---|---|
| 参数一律用元组 | `cur.execute(sql, (a,))` —— 单个参数也要那个逗号 |
| 事务里的函数要传 `cur` | `user_card_repo.deduct_balance(card_id, 10, cur=cur)` |
| 改完卡内资产要同步汇总 | `user_repo.refresh_summary(cur, user_id)`（在同一个事务里） |
| 时长单位是分钟 | `duration=120` 表示 2 小时；不要传小时数 |
| 状态是数字不是中文 | 用 `config` 里的 `ORDER_*` / `PAY_*` / `KIND_*` / `STATUS_*` / `ROLE_*` |
| 时间列叫 create_time | 不是 `created_at`；没有 `updated_at`，是 `update_time` |
| 页面必须在 app.py 注册 | `st.Page("ui/pages/user/xxx.py", title="...")`，否则点不到 |
| 管理端页面第一行 | `require_role("admin")` |
| 改完数据要刷新 | `st.rerun()` |
| 列表页要分页 | 服务端 `LIMIT/OFFSET`，别把整表拉进 `st.dataframe` |
| 宽度参数用 width | `width="stretch"`，不要用已废弃的 `use_container_width=True` |
