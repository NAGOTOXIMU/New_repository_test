# 接口速查表

> 记不住函数名的时候翻这里。所有函数都在 `db/`、`repository/`、`services/` 下。
> 表里 `→` 后面是**返回值**。

---

## 一、db/ —— 连接与事务

### `db/connection.py`

| 用法 | 说明 |
|---|---|
| `from db.connection import read_cursor, write_cursor` | 平时只用这两个 |
| `with read_cursor() as cur:` | 只读查询，自动开关连接 |
| `with write_cursor() as cur:` | 写入，自动开关连接 + 提交/回滚 |
| `check_connection()` → `(bool, 说明)` | 连通性自检（排查问题用） |

### `db/uow.py` —— 事务（多步同成同败）

```python
from db.uow import uow

with uow() as cur:
    ...多条写操作，比如"扣钱 + 写预约"...
# 正常走完自动 COMMIT；中间抛异常自动 ROLLBACK
```

### `db/init_db.py` —— 命令行工具

```bash
python -m db.init_db              # 建库建表（会先提示确认，因为会清空数据）
python -m db.init_db --yes        # 跳过确认
python -m db.init_db --with-seed  # 连测试数据一起灌
```

## 二、repository/ —— 数据访问（写界面时主要用这些）

### `user_repo` 用户表

| 函数 | 说明 |
|---|---|
| `get_by_username(username)` | → dict / None（**含密码**，登录校验用） |
| `get_by_id(user_id)` | → dict / None（不含密码） |
| `exists_username(username)` | → True / False |
| `exists_phone(phone)` | → True / False |
| `create(username, password_hash, real_name, phone, email=None)` | → 新 user_id |
| `update_profile(user_id, real_name, phone, email=None)` | → 影响行数 |
| `update_password(user_id, password_hash)` | → 影响行数 |
| `update_status(user_id, status)` | status 用 `'正常'` / `'冻结'` |
| `list_paged(keyword=None, offset=0, limit=20)` | → list[dict]（管理端分页） |
| `count(keyword=None)` | → int（配 paginated 用） |

### `store_repo` 门店表

| 函数 | 说明 |
|---|---|
| `get_by_id(store_id)` | → dict / None |
| `list_all(status=None)` | 传 `'营业'` 只取营业中（用户端用） |
| `list_paged(keyword=None, offset=0, limit=20)` | → list（管理端） |
| `count(keyword=None)` | → int |
| `create(name, address, phone=None, open_time="08:00:00", close_time="22:00:00")` | → store_id |
| `update(store_id, **fields)` | 例：`update(1, name="新名字")` |
| `update_status(store_id, status)` | `'营业'` / `'停业'` |

### `seat_repo` 座位表

| 函数 | 说明 |
|---|---|
| `get_by_id(seat_id)` | → dict / None |
| `list_by_store(store_id, status=None)` | 某门店的座位 |
| **`list_available(store_id, reserve_date, start_time, end_time)`** | **某时段仍空闲的座位**（预约页用） |
| `is_free(seat_id, reserve_date, start_time, end_time)` | → True / False |
| `create(store_id, seat_no, zone=None, price_per_hour=0)` | → seat_id |
| `batch_create(store_id, seats)` | seats 是 `[(编号, 区域, 单价), ...]`，→ 条数 |
| `update(seat_id, **fields)` / `update_status(seat_id, status)` | `'可用'` / `'维修'` / `'停用'` |
| `count_by_store(store_id, status=None)` | → int |

### `card_type_repo` 卡种表

| 函数 | 说明 |
|---|---|
| `get_by_id(card_type_id)` | → dict / None |
| `list_online()` | 上架的卡种（用户端买卡页用） |
| `list_paged(offset=0, limit=20)` / `count()` | 管理端 |
| `create(name, kind, price, face_value=None, total_times=None, total_hours=None, valid_days=365, discount=1.00)` | kind 取 `'储值'` / `'次卡'` / `'时长卡'` |
| `update(card_type_id, **fields)` / `update_status(card_type_id, status)` | `'上架'` / `'下架'` |

### `user_card_repo` 用户持有的卡（钱都在这）

| 函数 | 说明 |
|---|---|
| `generate_card_no()` | → 新卡号字符串 |
| `get_by_id(card_id)` / `get_by_no(card_no)` | → dict / None |
| `list_by_user(user_id)` | 所有卡（含过期） |
| **`list_active_by_user(user_id)`** | **可用卡（状态正常且未过期）** |
| `get_for_update(cur, card_id)` | **事务内锁卡**，只在 `with uow()` 里用 |
| `create(card_no, user_id, card_type_id, balance=0, remaining_times=None, remaining_hours=None, expire_at=None, cur=None)` | → card_id |
| `add_balance(card_id, amount, cur=None)` | 加钱 |
| **`deduct_balance(card_id, amount, cur=None)`** | 扣钱，→ **1 成功 / 0 余额不足** |
| `add_times` / `deduct_times(card_id, times=1, cur=None)` | 次数，返回同上 |
| `add_hours` / `deduct_hours(card_id, hours, cur=None)` | 时长，返回同上 |
| `update_status(card_id, status)` | `'正常'` / `'冻结'` / `'已过期'` / `'已用完'` |

### `reservation_repo` 预约表

| 函数 | 说明 |
|---|---|
| `generate_order_no()` | → 新单号 |
| `get_by_id(reservation_id)` / `get_by_order_no(order_no)` | → dict / None |
| `is_slot_taken(seat_id, reserve_date, start_time)` | → True / False |
| `create(order_no, user_id, seat_id, reserve_date, start_time, end_time, hours, amount, card_id=None, cur=None)` | → reservation_id；**撞唯一索引会抛 IntegrityError** |
| `cancel(reservation_id, cur=None)` | 置 `active_flag=NULL` 释放时段，→ 行数 |
| `update_status(reservation_id, status)` | `'待使用'` / `'使用中'` / `'已完成'` |
| `list_by_user(user_id, offset=0, limit=20)` / `count_by_user` | 我的订单（带座位号、门店名） |
| `list_paged(store_id=None, status=None, offset=0, limit=20)` / `count_paged` | 管理端 |
| `count_by_status(status)` / `count_between(start, end, store_id=None)` | 看板用 |

### `recharge_repo` 充值订单表

| 函数 | 说明 |
|---|---|
| `generate_order_no()` | → 新单号 |
| `get_by_id` / `get_by_order_no(order_no)` | → dict / None |
| `create(order_no, user_id, card_type_id, amount, pay_method="微信")` | → recharge_id |
| **`mark_paid(recharge_id, card_id=None, cur=None)`** | → 1 成功 / 0 已支付过（防重复支付） |
| `cancel(recharge_id)` | 只能取消待支付的 |
| `list_by_user` / `count_by_user` / `list_paged` / `count_paged` | 列表 |
| `sum_amount(start_date=None, end_date=None)` | → 已支付金额合计 |
| `revenue_by_day(start_date, end_date)` | → 按天营收（画折线图） |
| `count_by_card_type()` | → 各卡种销量（画饼图） |

### `admin_repo` 管理员表

| 函数 | 说明 |
|---|---|
| `get_by_id(admin_id)` / `get_by_username(username)` | 后者**含密码** |
| `exists_username(username)` | → True / False |
| `create(username, password_hash, real_name, phone=None, store_id=None)` | store_id 传 None 是超管 |
| `list_paged(offset=0, limit=20)` / `count()` | 管理端 |
| `update_profile(admin_id, real_name=None, phone=None, store_id=None)` | 只改传进来的 |
| `update_status(admin_id, status)` | `'正常'` / `'停用'` |

## 三、services/ —— 业务层（界面调这一层）

### `user_service`

| 函数 | 说明 |
|---|---|
| `register(username, password, real_name, phone, email=None)` | → dict；失败抛 `BizError` |
| `login(username, password)` | → dict（含 `role`，不含密码）；失败抛 `BizError` |

### `order_service` 预约

| 函数 | 说明 |
|---|---|
| `reserve(user_id, seat_id, reserve_date, start_time, hours=1, card_id=None)` | → dict（单号、座位号、金额）；余额不足/被抢走都抛 `BizError` |
| `cancel(reservation_id, user_id)` | → dict（退款金额） |
| `check_in(reservation_id)` | 待使用 → 使用中 |
| `finish(reservation_id)` | 使用中 → 已完成 |
| `list_my_orders(user_id, page=1, page_size=20)` | → **(数据列表, 总条数)** |
| `list_orders(store_id=None, status=None, page=1, page_size=20)` | → (列表, 总数) |

### `recharge_service` 充值

| 函数 | 说明 |
|---|---|
| `list_card_types()` | → 上架卡种列表 |
| `create_order(user_id, card_type_id, pay_method="微信")` | → dict（含 order_no） |
| `pay(order_no)` | 支付并到账，→ dict（卡号）；重复支付抛 `BizError` |
| `cancel_order(order_no)` | 取消待支付订单 |
| `list_my_recharges(user_id, page=1, page_size=20)` | → (列表, 总数) |
| `list_all(status=None, page=1, page_size=20)` | → (列表, 总数) |

### `password` / `exceptions`

| 函数 | 说明 |
|---|---|
| `hash_password(password)` | → `"盐$哈希"` 字符串 |
| `verify_password(password, stored)` | → True / False |
| `BizError` | 业务异常，界面层 `except BizError as e: st.error(str(e))` |

### `ui/components.py`

| 函数 | 说明 |
|---|---|
| `require_role(*roles)` | 放在管理端页面第一行：`require_role("admin")`，不满足就 `st.stop()` |

## 四、常用写法（照抄就行）

### 1. 查一条数据

```python
from repository import user_repo

user = user_repo.get_by_username("admin")
if user is None:
    st.warning("没有这个用户")
else:
    st.write(user["real_name"])
```

### 2. 查一列数据画表格

```python
from repository import store_repo
import pandas as pd

stores = store_repo.list_all()
st.dataframe(pd.DataFrame(stores))
```

### 3. 写入（自动提交）

```python
from repository import store_repo
new_id = store_repo.create("新门店", "某地址", "0571-1234")
st.success(f"新建成功，id = {new_id}")
```

### 4. 分页列表（服务端分页）

```python
from services import order_service

page = st.session_state.get("page", 1)
rows, total = order_service.list_my_orders(user_id, page=page, page_size=20)
st.dataframe(pd.DataFrame(rows))
st.caption(f"共 {total} 条，第 {page} 页")
```

### 5. 业务操作要接住 BizError

```python
from services import order_service
from services.exceptions import BizError

if st.button("确认预约"):
    try:
        result = order_service.reserve(uid, seat_id, date, "10:00:00", 2, card_id)
        st.success(f"预约成功，扣费 {result['amount']} 元")
        st.rerun()
    except BizError as e:
        st.error(str(e))          # 余额不足、时段被抢…都在这
```

### 6. 表单里保存用户输入

```python
with st.form("f"):
    name = st.text_input("门店名")
    addr = st.text_input("地址")
    ok = st.form_submit_button("保存")

if ok:
    if not name.strip():
        st.error("门店名不能为空")
    else:
        store_repo.create(name, addr)
        st.success("已保存")
        st.rerun()
```

### 7. 登录态

```python
user = st.session_state["user"]       # 登录后一定有；app.py 已经拦过
uid  = user["user_id"]
role = user["role"]                   # "user" 或 "admin"
```

## 五、几个容易忘的点

| 事 | 怎么做 |
|---|---|
| 参数一律用元组 | `cur.execute(sql, (a,))` —— 单个参数也要那个逗号 |
| 事务里的函数要传 `cur` | `user_card_repo.deduct_balance(card_id, 10, cur=cur)` |
| 页面必须在 app.py 注册 | `st.Page("ui/pages/user/xxx.py", title="...")`，否则点不到 |
| 管理端页面第一行 | `require_role("admin")` |
| 改完数据要刷新 | `st.rerun()` |
| 列表页要分页 | 服务端 `LIMIT/OFFSET`，别把整表拉进 `st.dataframe` |
